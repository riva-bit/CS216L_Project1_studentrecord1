# Student Record System

## Project Description

Student Record System is a Java-based application used to manage student records. It allows users to add, delete, search, update, sort student records by GPA, and undo the last delete or update.

## Data Structures Used

* Linked List
* Stack
* Node

## Features

* Add Student
* Display Students
* Search Student
* Delete Student
* Sort Students by GPA
* Undo Last Delete
* Update Student
* Undo Last Update

## Time Complexity

| Operation        | Time Complexity |
| ---------------- | --------------- |
| Add Student      | O(n)            |
| Display Students | O(n)            |
| Search Student   | O(n)            |
| Delete Student   | O(n)            |
| Sort by GPA      | O(n²)           |
| Undo Last Delete | O(n)            |
| Update Student   | O(n)            |
| Undo Last Update | O(n)            |
